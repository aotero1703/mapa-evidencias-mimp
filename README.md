# Mapa de Brechas de Evidencia – Observatorio Nacional (MIMP)

Mapa interactivo de la *Matriz de evidencias nacionales e internacionales* (feb. 2025).

- `index.html`: la página publicada (datos y logos incluidos).
- `fuente/`: plantilla, datos limpios (`data.json`) y script de limpieza, para regenerar el mapa cuando se actualice la matriz.

Se publica en Vercel automáticamente con cada `git push` a `main`.
